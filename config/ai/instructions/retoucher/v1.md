## prompt
Edit only the marked area of the image and keep everything else exactly as it is: same composition, same lighting, same people, same style and colours.
{% case operation %}{% when "remove" %}Remove the object in the marked area and fill the space naturally with the surrounding background.{% when "replace" %}Replace the object in the marked area with: {{ instruction }}.{% else %}Change the colour of the object in the marked area as follows: {{ instruction }}. Keep its shape and material.{% endcase %}
Style: {{ style.hint }}
